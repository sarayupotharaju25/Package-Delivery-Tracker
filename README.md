# \# 📦 Package Delivery Tracker

# 

# A console-based Java application for managing customers, delivery agents, parcels, and billing in a package delivery system.

# 

# \## 📌 Project Overview

# 

# The Package Delivery Tracker is designed to simplify package delivery management through a console-based interface.

# 

# The application allows users to register customers, manage delivery agents, create and track parcels, and handle billing operations.

# 

# \## 🚀 Features

# 

# \- 👤 Customer registration and management

# \- 🚚 Delivery agent management

# \- 📦 Parcel creation and tracking

# \- 💰 Billing management

# \- 🔍 Search customer and parcel details

# \- 📋 View customer, agent, and parcel information

# \- 🖥️ Simple console-based menu system

# \- 🔄 CRUD-style operations using Java collections

# 

# \## 🛠️ Technologies Used

# 

# \- Java

# \- Object-Oriented Programming

# \- Java Collections

# \- ArrayList

# \- Iterator

# \- Interfaces

# \- Exception Handling

# \- Eclipse IDE
